# Roadmap

Planned features, roughly in order.

- [ ] Hook library: save hook templates and reuse them across reels
- [ ] Export the week plan to Markdown and CSV
- [ ] Posting-streak and "gap" warnings (days with nothing scheduled per page)
- [ ] Tags/series for reels, filter by tag
- [ ] Import ideas from a plain text file (one per line)
- [ ] Simple stats: reels per status per page
- [ ] `reelplanner today` - what to film and post today
- [ ] Interactive TUI (textual) for browsing and editing
- [ ] Optional local web dashboard (FastAPI + HTMX)
- [ ] Recurring slots ("every Mon/Wed/Fri on @aisketched")
